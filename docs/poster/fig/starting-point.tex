% Published: 85.8% vs CBOW 70.0% (report related-work table). Half-bit chance 1/2,
% constant prior 96.5% (57-target audit, tab:audit); exact word 1.068% (tab:qcse-other).

	\node[verdict] at (0,-11) {\textbf{Published [1]:} 85.8\% accuracy (CBOW 70.0\%),
